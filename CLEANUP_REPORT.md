# Repository Cleanup Report

## Scope

This cleanup was conservative and preserved the working RL/research pipeline. No
tracked source, baseline, model checkpoint, dataset, evaluation script, or
research configuration was deleted without a verified reference trace.

## Baseline

- Repository root: `baselines_openai/`, `evonav_env/`, project reports, and Git metadata.
- `evonav_env` contains the active EvoNav pipeline, CrowdSim environments, RL code,
  GST implementation, baselines, experiment scripts, tracked checkpoints, and
  reproducibility data.
- 379 tracked files were present at inventory time.
- The working tree also contained runtime caches, temporary files, and generated
  smoke/build logs outside the tracked source set.

## Files Deleted

- Runtime `__pycache__/` directories throughout the repository.
- `.pytest_cache/` directories.
- `evonav_env/.pip_cache/`.
- `evonav_env/.tmp/` temporary/debug artifacts.
- The untracked root `rvo2-install.log` build log.

No tracked source or research artifact was deleted.

## Files Modified

- `.gitignore`: added common Python caches, build directories, temporary files,
  and `*.log` exclusions at the repository and EvoNav levels.

## Dependencies Removed

None. Dependency removal was not provable from static inspection, and the
legacy Gym/RVO2/GST stack is part of the reproducible environment contract.

## Dead Code / Duplicates

No production code was removed. `rl/networks` is actively imported by training,
evaluation, and Stage II/III. `rl/vec_env` is also actively imported by the
network environment factory. Smoke runners, dataset collection, reporting,
DS-RNN training, baselines, and trained-model directories are referenced by
entry points or documentation and were retained.

The GST `README-old.md`, legacy upstream scripts, tracked notebooks, baseline
assets, and experiment results were retained because their lack of use could
not be proven and they may support reproduction or historical comparison.

## Validation

- Existing focused EvoNav tests: `84 passed` with `-m "not slow"`.
- Stage I/evolver regression tests: `8 passed`.
- Ollama client tests: `5 passed`.
- Changed Python files compiled successfully with Python 3.10.
- Imports traced and verified for `baselines`, `rl.networks`, and `crowd_sim`.
- The real GPU EvoNav smoke run completed previously through Stage I, Stage II,
  Stage III, and H-sweep; GST reported `cuda:0`.
- CLI entry points and pipeline sources were inspected; no source deletion was
  performed that could affect startup.
- Post-cleanup grep found no stale split-Python launcher or PYTHONPATH workaround
  references.

## Estimated Reduction

The cleanup removes runtime-only cache and temporary content rather than source
code. It reduces local workspace clutter and prevents generated logs/caches from
returning to Git. The exact byte reduction is machine-dependent because cache
contents are regenerated by test and package tooling.

## Remaining Technical Debt

- The repository still contains two upstream codebases (`baselines_openai` and
  `gst_updated`) because both are part of the research pipeline or reproducibility
  surface.
- Some upstream GST scripts contain historical absolute Linux paths and old
  dependency documentation; they are not used by the current EvoNav entry point.
- The legacy Gym API and old RL implementation remain intentional compatibility
  constraints.
- Generated experiment results and tracked model assets were not aggressively
  pruned because doing so would reduce reproducibility.
